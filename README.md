# Fala

Dita em qualquer app e controla o teu Mac e o teu PC a partir do iPhone, de qualquer rede.

- **iPhone**: App Store / TestFlight
- **Mac**: `Fala.dmg` (assinado e notarizado pela Apple)
- **Windows**: `FalaSetup.exe`

Depois de instalar no computador, abre a Fala no iPhone, menu ☰, "Ligar ao Mac/PC" e lê o QR.
Tudo vai cifrado ponta a ponta com o código do QR; o relay só vê bytes.
